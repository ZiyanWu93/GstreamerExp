# Runtime

The project runtime is local to GstreamerExp. It is operated through the project CLI, experiment runner, generated analyses, and the local static viewer.

## Entrypoints

- `index.html`
- `features.html`
- `python3 cli.py`
- `python3 experiment.py`

The Entelesis runtime mount is not applicable for this project. Entelesis should discover, link, and check the project without turning its local experiment runner into a dashboard app.
