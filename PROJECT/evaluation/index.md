# Evaluation

Evaluation uses one fixed framework: throughput, quality, latency, adaptation, and stability.

## Evidence

- Hypothesis records live under `docs/HYPOTHESES.md` and `specs/hypotheses`.
- Run records live under `runs` and `runs/experiments`.
- Analysis artifacts live under `analysis` and `analysis/hypotheses`.
- Reports live under `analysis/hypotheses/results`.

Claims should distinguish measured findings from inferred explanations.
