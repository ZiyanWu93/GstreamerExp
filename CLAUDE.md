# Claude Instructions

This project follows the Project Work Protocol.

Before editing, read `project.yaml` and `README.md`. Use the project profile to
understand Goal, Runtime, DSL, Application, Roadmap, and Evaluation.

Edit authoritative source records instead of generated outputs. When the
project declares local validation in `project.yaml`, run the relevant safe
checks before reporting completion, or explain why they could not be run.
